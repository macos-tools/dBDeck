# dBDeck（音量岛）

[English](README.md)

dBDeck 是一款轻量的 macOS 菜单栏分应用音量控制工具，支持 macOS 14.2 及以上版本。

> dBDeck 目前仍处于早期阶段，仅提供源代码。仓库暂未提供面向普通用户、经过苹果公证的应用安装包。

## 功能

- 在不改变系统音量的情况下，将每个应用的音量调节至 0%–200%。
- 单独静音或取消静音某个应用。
- 按 Bundle Identifier 记住每个应用的音量和静音状态。
- 跨启动记住曾经播放过声音、且能够识别的应用。
- 依次排列正在播放、正在运行且有播放历史、已停止但有播放历史的应用；每一组内部按累计播放时长排序。
- 在可滚动的菜单栏混音面板中显示符合条件的应用，不显示 Dock 图标。
- 根据 macOS 的语言自动使用英文或简体中文。

从未播放过声音的应用不会显示。后台服务、应用内的辅助进程和原始进程 ID 会被隐藏，或归并至所属应用。已删除的应用不会出现在面板中，但体积很小的历史记录仍会保留。当有播放历史且仍已安装的应用超过 10 个时，停止运行并且超过 7 天没有播放的项目会被隐藏；这项整理每天最多执行一次。

当音量为默认的 100% 且未静音时，dBDeck 会移除对应的音频处理链路，让声音正常直通。

## 隐私与权限

dBDeck 不会录制、存储或传输音频，也没有联网功能。音频处理只在本机进行。

应用会在 `UserDefaults` 中保存以下本地数据：

- Bundle Identifier、显示名称和上次记录的应用路径。
- 累计播放秒数和最近一次播放日期。
- 每个应用的音量和静音状态。
- 被隐藏的长期未使用记录，以及上次整理列表的时间。

dBDeck 使用苹果的 Core Audio Process Tap API、私有聚合设备以及实时增益回调。当某个应用被静音或音量不等于 100% 时，macOS 会请求“系统音频录制”权限。音量为 100% 且未静音时，不会保持音频处理链路。

## 环境要求

- macOS 14.2 或更高版本。
- Xcode 16，或兼容的 Swift 6 工具链。

## 构建与运行

```sh
./script/build_and_run.sh
```

脚本会构建 `dist/dBDeck.app`，为本地开发添加临时签名，然后启动应用。这个构建没有使用 Developer ID 签名，也没有经过苹果公证，不适合直接分发。

可选模式：

```sh
./script/build_and_run.sh --verify
./script/build_and_run.sh --logs
./script/build_and_run.sh --debug
```

## 测试

```sh
./script/test.sh
```

测试脚本会运行 Swift Package 测试，覆盖设置持久化、播放历史与排序、Store 状态变化、应用名称本地化，以及实时增益与静音的采样处理；随后还会使用真实发声的测试应用验证 Core Audio 发现逻辑。脚本不会停止已经运行的 dBDeck 实例。

如需在 Debug 构建中验证完整的 Process Tap 与聚合设备链路，请运行：

```sh
./script/verify_route.sh
```

首次运行这条链路时，macOS 会请求“系统音频录制”权限。链路检查会覆盖应用发现、Process Tap 创建、增益变化、静音和清理；AudioDSP 测试会另外断言精确的采样值。

## 实现方式

- 使用 SwiftUI `MenuBarExtra` 创建由系统管理的菜单栏项目和混音面板。
- 使用 Core Audio Process Tap 和私有聚合设备完成分应用音频处理。
- 使用小型 C 实时回调和原子增益状态处理采样。
- 将播放历史和音量偏好编码为 JSON，保存在本机 `UserDefaults` 中。

## 当前范围

当前版本跟随系统默认输出设备。暂不包含分应用输出设备、自动 Duck、Profiles、EQ、全局快捷键、CLI、Shortcuts 和 Raycast 集成。
